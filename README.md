### 기획 의도
다크앤 다커는 불미스러운 사건이 아니었다면 게임 자체는 해외에서도 주목받을 만큼 인기가 좋았던 게임으로 이와 비슷하게 만들어보고자 하였음

<br/>

### 게임 특징
- 주인공은 고블린으로, 적들에 비해 키가 작음
- 몬스터 뿐만 아니라 인간 탐험가와 전투하게 됨
- 인간 탐험가는 몬스터와도 적대이기 때문에 플레이어 뿐만 아니라 몬스터와도 전투
- 인간 탐험가의 경우 인간이기 때문에 지능이 있다는 설정으로 플레이어의 장비의 수준과 자신의 체력에 따른 도망이 구현되어 있음
